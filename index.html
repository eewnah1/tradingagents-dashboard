TradingAgents Project on Transwarp Cloud

Full overview of the TradingAgents multi-agent LLM trading framework, followed by the CPU vs GPU benchmark run on Transwarp Cloud.

1. What is TradingAgents?

TradingAgents is a multi-agent trading framework that mirrors a real-world trading firm. Specialized LLM-powered agents collaboratively evaluate market conditions, debate trade ideas, and reach a final trading decision through a LangGraph workflow.

Fundamentals Analyst

Evaluates company financials, intrinsic value, and potential red flags from fundamentals data.

Sentiment Analyst

Aggregates news, StockTwits, and Reddit chatter into a single sentiment read for short-term mood.

News Analyst

Monitors global news and macroeconomic indicators and interprets their impact on markets.

Technical Analyst

Uses indicators such as MACD, RSI, Bollinger Bands, ATR, and VWMA to detect price patterns and momentum.

Researcher Team

Bullish and bearish researchers debate the analysts' insights and balance potential gains against risks.

Trader Agent

Composes the research reports into an informed trading decision, including timing and magnitude.

Risk Management

Assesses portfolio risk using volatility, liquidity, and other risk factors to adjust strategies.

Portfolio Manager

Approves or rejects the trade proposal. If approved, the order is sent to a simulated exchange.

2. Data & Compute Pipeline

  • Data sources: Yahoo Finance (yfinance), Alpha Vantage, FRED, Polymarket, and other configured vendors.
  • Indicators: Computed with stockstats (MACD, RSI, Bollinger, ATR, VWMA, MFI, SMA/EMA).
  • Workflow engine: LangGraph with structured-output agents and optional checkpoint resume.
  • Transwarp catalog: tradingagents_benchmark namespace, schema main.
  • Tables:
    • tradingagents_benchmark.main.synthetic_ohlcv — 100,000 synthetic 1-minute OHLCV rows.
    • tradingagents_benchmark.main.ohlcv_bench — 20,000,000 rows generated by cross join for SQL benchmarking.
  • Compute: CPU Data Warehouse Cognitive_CPU_Starter and GPU Data Warehouse DW-G2-1.

3. CPU vs GPU Benchmark

The benchmark compares technical-indicator-style analytics across CPU and GPU compute. The local CPU Python baseline runs the TradingAgents-style indicator set (MACD, RSI, Bollinger, ATR, VWMA) on 100k rows. The Transwarp comparison runs a heavy SQL query over 20M rows with partitioned moving averages, VWAP, and correlation on the CPU and GPU Data Warehouse engines.

Note: The Transwarp CPU General Compute (Cognitive_General_Starter) is CPU-only and has auto-resume disabled, so the Python stockstats workload could not run directly on Transwarp. The CPU-vs-GPU comparison therefore uses the GPU Data Warehouse (DW-G2-1) to run the same SQL analytics workload on GPU, showing a 4.85x best-case speed-up versus the CPU Data Warehouse on a 20M-row TradingAgents-style OHLCV benchmark. The first GPU run includes a warm-up/compile step; subsequent runs hold steady around 0.72 s.
