Executive Summary

This dashboard benchmarks the eewnah1/GPU-Accelerated-Multi-Agent-Reinforcement-Learning-for-High-Frequency-Trading workload on Transwarp Cloud. The framework trains heterogeneous RL agents (market makers, execution agents, directional traders) inside a JAX limit-order-book simulator using real-style LOBSTER data. Because no GPU-backed General Compute notebook is available in this workspace, the CPU-vs-GPU comparison uses the same SQL LOB analytics workload on the GPU Data Warehouse (DW-G2-1) versus the CPU Data Warehouse (Cognitive_CPU_Starter).

Key take-away: the GPU Data Warehouse achieves a 1.25x best-case speed-up over the CPU Data Warehouse on the 2.6M-row LOB aggregate benchmark, while the local CPU JAX environment runs at 112 steps/s for a single BaseLOBEnv step.

System Architecture

Core Stack

  • JAX — JIT-compiled, GPU-accelerated numerical computing with vmap for parallel episodes.
  • JAX-LOB — GPU-accelerated limit order book simulator (order book, matching engine, trade history).
  • JaxMARL — Multi-agent RL environments and algorithms extended to financial trading.
  • Flax / Optax — Neural network and optimizer back-ends for the IPPO/RNN agents.
  • Hydra — Configuration management for environment and training YAML/JSON configs.
  • Weights & Biases — Optional experiment tracking and hyper-parameter sweeps.

Pipeline

  1. Load raw LOBSTER message / orderbook CSV pairs.
  2. Pre-process and cache LOB windows as JAX arrays (or pickles).
  3. Reset the BaseLOBEnv to a random window each episode.
  4. Each RL step processes n_data_msg_per_step market messages, agent action messages, and cancellations.
  5. IPPO with GRU policy/value networks trains thousands of parallel envs (default 4,096).

Agent Types

Market Making Agent (MM)

Provides liquidity by posting bid/ask quotes and earning the spread while managing inventory risk.

  • Action spaces: spread_skew, fixed_quants, AvSt, directional_trading, simple, bobStrategy, bobRL, fixed_prices
  • Observation spaces: basic, engineered, message-based variants
  • Reward functions: PnL-based with inventory penalties (Spooner family, complex, portfolio value, delta portfolio value)
  • Default config: 2_player_fq_fqc.json uses fixed_quants + spooner_asym_damped2

Execution Agent (EXE)

Executes large parent orders with minimal market impact over an episode horizon.

  • Tasks: random, buy, sell
  • Action spaces: fixed_quants, fixed_quants_complex, fixed_prices, simplest_case, twap
  • Observation space: engineered or basic
  • Reward: Slippage-based with end-of-episode penalty (normal, finish_fast, simplest_case)
  • Default task size: 600 shares

Directional Trading

Simple directional strategy that can do nothing, buy at best ask, or sell at best bid. Shares the market-making agent class.

  • Action space: 3 discrete actions: no-op, buy, sell
  • Reward: Portfolio value

Reward Functions

Market-making rewards decompose into realized buy/sell PnL, rebate income, inventory PnL, and optional inventory penalties:

  • spooner — buyPnL + sellPnL + rebate + InventoryPnL
  • spooner_damped — Spooner with dampened inventory PnL
  • spooner_asym_damped / spooner_asym_damped2 — Asymmetric dampening with configurable inventoryPnL_eta and inventoryPnL_gamma
  • spooner_scaled — Scaled by inventory for stability
  • complex — Approximate realized + unrealized PnL blend
  • portfolio_value — Mark-to-market net worth
  • delta_portfolio_value — Step-to-step change in net worth
  • buy_sell_pnl — Pure cash-flow PnL
  • zero_inv — Debugging reward penalizing inventory

Inventory penalty options: none, linear, quadratic, threshold, exp4.

Data Pipeline

LOBSTER Data

  • Raw files: paired <STOCK>_<DATE>_34200000_57600000_message_10.csv and orderbook_10.csv
  • Stored under data/rawLOBSTER/<STOCK>/<TIME_PERIOD>/
  • First training run pre-processes and caches arrays/pickles; subsequent runs are much faster.

Transwarp Catalog Assets

  • gpu_hft.main.synthetic_orderbook — 12,999 rows
  • gpu_hft.main.bench_lob — 2,599,800 rows (2.6M-row benchmark table built via CROSS JOIN generate_series(1, 200))
  • Namespace tradingagents_benchmark prepared for future results.

Reproduce the Workload

Local Conda Setup

conda create -n jaxmarl_hft python=3.10
conda activate jaxmarl_hft
pip install "jax[cuda12]"
pip install -r requirements.txt
export PYTHONPATH="$(pwd):$PYTHONPATH"

Train the Default Two-Agent Policy

python3 gymnax_exchange/jaxrl/MARL/ippo_rnn_JAXMARL.py \
    --config-name="ippo_rnn_JAXMARL_2player" \
    WANDB_MODE="disabled"

Docker (x86_64/amd64)

make build
make run
make ppo_2player gpu=0

SQL Benchmark Query (Transwarp Data Warehouse)

SELECT COUNT(*), AVG(quantity), SUM(quantity)
FROM gpu_hft.main.bench_lob
WHERE side = 'B';

Known Constraints & Status

  • GPU General Compute unavailable: No GPU-backed Python notebook product is exposed in this Transwarp workspace, so JAX training cannot run on GPU here.
  • CPU General Compute blocked: Cognitive_General_Starter has automatic resume disabled and cannot be resumed without owner action.
  • Data Warehouse GPU works for SQL: DW-G2-1 (G2 Large x2) successfully runs the LOB analytics benchmark, giving the 1.25x best-case speed-up over the CPU warehouse.
  • Marketplace is read-only: Datasets are curated by Transwarp; no user publishing UI.
