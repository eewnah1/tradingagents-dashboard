Note: A GPU-backed General Compute instance (JAX notebook) is not available in this Transwarp workspace, so the JAX HFT benchmark could not run on GPU. The CPU-vs-GPU comparison above uses the GPU Data Warehouse (DW-G2-1) to run the same SQL LOB analytics workload on GPU, demonstrating a 1.25x best-case speed-up over the CPU Data Warehouse (Cognitive_CPU_Starter). Synthetic LOBSTER orderbook data (12,999 rows) was generated for the GPU HFT repo and imported into Transwarp Catalog as gpu_hft.main.synthetic_orderbook. A larger 2.6M-row benchmark table gpu_hft.main.bench_lob was built from it for the SQL comparison.
